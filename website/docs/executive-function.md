# Executive Function Skills for Money Choices

Money choices often involve tracking, waiting, prioritizing, saving, comparing prices, and adjusting plans. Executive function helps kids make money tasks visible and repeatable.

This page is the local doorway into the Literacy for Kids [Executive Function Toolkit](https://www.literacy-for-kids.com/docs/toolkits/executive-function), connected to the money skills this curriculum builds.

## A few core ideas

- **Tracking reduces guessing.** You can only manage what you can see.
- **Saving works better with a visible plan.** A goal you can picture is easier to reach.
- **Prioritizing helps when wants compete.** Must / should / could sorts the pile.
- **Budgets need restart points after mistakes.** A slip is not the end of the plan.

## When this shows up

- When tracking spending feels annoying
- When saving for a goal
- When comparing prices or tradeoffs
- When a budget has too many parts
- When a money plan gets interrupted
- When you need to adjust after a spending mistake

## Tools that help

- **Spending tracker checklist** — the same quick steps each time.
- **Must / should / could** — for sorting wants.
- **Tiny first step** — write the goal.
- **Time estimate** — how long until you reach the goal?
- **Version 2 budget restart** — adjust after what you learned.

:::tip Executive Function Moment
A savings goal gets easier when it is visible. Write the goal, the amount, and the next tiny step. "Save money" is blurry; "put $2 in the jar today" is startable.
:::

:::caution Everyday task skills, not a diagnosis
These are everyday planning and task-management tools, not therapy, medical advice, disability evaluation, ADHD treatment, or a replacement for trusted adults, educators, caregivers, or qualified support. Kids should not be treated as lazy or broken when starting, focusing, organizing, or finishing is hard. If tasks feel consistently overwhelming, inaccessible, unsafe, or severely distressing, involve a trusted adult and appropriate support.
:::
